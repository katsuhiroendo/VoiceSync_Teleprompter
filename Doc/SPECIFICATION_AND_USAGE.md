# VoiceSync Teleprompter 仕様書・ユーザーガイド

## 1. 概要とプロジェクトの目的

**VoiceSync Teleprompter** は、YouTube動画などの撮影時に、撮影者がカメラ目線を維持しながら日本語または英語の原稿を自然に読み上げられる個人利用向けの音声追従型テレプロンプターWebアプリケーションです。

### 最大の特徴
- **リアルタイム音声追従スクロール**：単純な音量検出や固定速度スクロールではなく、マイクから取得した発話内容をリアルタイムに音声認識し、原稿とファジー照合して現在位置を特定・自動スクロールします。
- **自然な話し方への適応**：ゆっくり話した場合、速く話した場合、途中で数秒〜10秒以上沈黙した場合、言い間違いや一部単語の省略、原稿にないアドリブの挿入、前の文章の読み直し、次の段落へのジャンプに柔軟に対応します。
- **カメラ目線モード & フォーカスモード**：MacBook内蔵カメラの直下に原稿表示領域を集約する「カメラ目線モード」や、現在読んでいるフレーズだけを明るく強調する「フォーカスモード」を搭載しています。
- **完全無料・オフライン耐性・マルチデバイス対応**：ブラウザ標準の IndexedDB と Web Speech API / Web Audio API を活用し、外部の有料API課金なしで運用できます。

## 3. 起動方法・セットアップ手順

### 3.1 GitHub Pages（Web公開版）での利用とデプロイ手順
本リポジトリには GitHub Actions による静的エクスポート自動デプロイ（[`.github/workflows/deploy.yml`](../.github/workflows/deploy.yml)）が設定されており、ワークフロー内の `actions/configure-pages@v5` (`enablement: true`) によって GitHub Pages の構成と公開が自動で行われます。

- **公開URL**：`https://katsuhiroendo.github.io/VoiceSync_Teleprompter/`
- **初回有効化手順とエラー時（赤い `×` 表示）の対処法**：
  1. **リポジトリの公開設定の確認**：無料の GitHub アカウントで GitHub Pages を利用する場合は、リポジトリが **Public** である必要があります（Private の場合は **Settings ＞ General ＞ Danger Zone ＞ Change repository visibility** から Public に変更してください）。
  2. **Pages ソース設定の確認**：GitHubリポジトリ（`https://github.com/katsuhiroendo/VoiceSync_Teleprompter`）の上部メニュー **Settings** ＞ 左メニュー **Pages** を開き、**Build and deployment ＞ Source** が **`GitHub Actions`** になっていることを確認します（`Deploy from a branch` になっている場合は `GitHub Actions` に切り替えます）。
  3. **ワークフローの再実行（Re-run）**：設定切り替え前に実行された Actions がエラー（×）になっていた場合は、上部メニューの **Actions** タブを開き、該当のワークフローを選択して右上の **「Re-run all jobs」** をクリックします。
  4. **公開完了の確認**：`build` と `deploy` ジョブが緑色のチェックマーク（✓）になると、MacBook・iPad・スマートフォンのブラウザから上記公開URLを開くだけで、インストール不要ですぐに利用できます。
  5. **以降の更新**：`main` ブランチへ `git push` するたびに、自動的に単体テスト（`npm test`）と本番ビルド（`npm run build`）が走り、最新バージョンが公開URLへ反映されます。

## 4. 画面構成と基本的な使い方

アプリケーションは誤編集防止のため、**「原稿編集画面（編集モード）」** と **「プロンプター撮影画面（撮影モード）」** の2つに完全に分離されています。

### 4.1 原稿編集画面（編集モード）
起動直後に表示される画面です。左側のサイドバーで原稿一覧を管理し、右側のメインエディタで本文を執筆します。

1. **新規原稿の作成**：左上の **「＋ 新規原稿」** ボタンを押すと新しい原稿が作成されます。
2. **タイトル・本文の編集と自動保存**：タイトル欄や本文エリアに入力すると、即座にブラウザ内の IndexedDB へ自動保存されます（画面上部に「IndexedDB保存済」と表示されます）。ブラウザを閉じてもデータは消えません。
3. **言語の切り替え**：画面右上の言語セレクターから **「日本語 (ja-JP)」** または **「English (en-US)」** を選択します。選択した言語に合わせて音声認識エンジンと想定読み上げ時間の計算が切り替わります。
4. **キーワード検索**：左サイドバーの検索ボックスにキーワードを入力すると、タイトルおよび本文からリアルタイムに絞り込み検索ができます。
5. **原稿の複製・削除**：原稿リストの各項目にカーソルを合わせる（またはタップする）と、右側に **複製アイコン** と **削除アイコン** が表示されます。
6. **テキストファイルの読み込み・書き出し**：
   - **「ファイル読込 (.txt)」**：手元の `.txt` や `.md` ファイルを読み込んで新規原稿として登録します。
   - **「書き出し (.txt)」**：現在選択中の原稿を `.txt` ファイルとしてダウンロードします。
7. **撮影モードの開始**：右上の **「撮影モードを開始」** ボタンを押すと、原稿がロックされ撮影画面へ切り替わります。

---

### 4.2 プロンプター撮影画面（撮影モード）
カメラ目線での読み上げに集中するための Distraction-Free（不要UI自動非表示）画面です。再生開始後、約3秒間マウスやタッチ操作がないと上下の操作バーが自動的にフェードアウトし、画面タップやマウス移動で即座に再表示されます。

#### 上部ステータス＆クイック設定バー
- **編集へ戻る**：撮影モードを終了し、原稿編集画面に戻ります。
- **状態表示バッジ & マイク音量メーター**：現在の状態（`待機中` / `マイク接続中` / `音声認識中` / `発話検出中` / `原稿照合中` / `一時停止中` / `エラー`）と、マイク入力レベルのリアルタイムインジケーターを表示します。カメラ録画中は赤色の **`● REC 00:15`** タイマーバッジが隣に表示されます。
- **カメラ起動 / カメラON**：MacBook内蔵カメラ（または外部接続Webカメラ）のプレビュー映像を起動・停止します。
- **小窓表示 / 背景透過 / 映像非表示**：カメラ起動中にクリックすると、プレビューの表示スタイル（Webカメラ直下の小窓 PiP ／ 原稿の背面に透過表示 ／ プレビュー非表示）をワンクリックで切り替えられます。
- **文字サイズ変更（`－` / `＋`）**：撮影画面のままワンクリックで文字サイズ（16px〜100px）を微調整できます。
- **カメラ目線**：MacBook内蔵カメラ直下に表示領域を限定する「カメラ目線モード」のON/OFFを切り替えます。
- **フォーカス**：現在読み上げ中のフレーズを明るく、周囲の文章を暗くする「フォーカスモード」のON/OFFを切り替えます。
- **デバッグ**：画面右下の「リアルタイム音声認識・照合デバッグパネル」の表示/非表示を切り替えます。
- **全画面表示**：ブラウザのフルスクリーン表示を切り替えます。
- **設定アイコン**：詳細な表示・追従パラメータを調整する設定モーダルを開きます。

#### 下部レコーディング操作ドック
- **スクロールモード切替**：
  - **音声追従**：マイクからのリアルタイム音声認識で原稿位置を特定し自動スクロールします（デフォルト）。
  - **一定速度**：設定した速度（`px/s`）で滑らかに等速スクロールします。
  - **手動**：タッチスワイプ、マウスホイール、またはキーボード矢印キーで手動スクロールします。
- **先頭へ**：スクロールを停止し、原稿の1文目（先頭）へ滑らかに戻ります。
- **前段落 / 次段落**：現在位置から前の段落の先頭、または次の段落の先頭へ瞬時にジャンプします。
- **音声認識開始 / 一時停止 / 再開**：メインの再生・停止ボタンです。
- **● カメラ録画開始 / ■ 録画停止**：MacBookのカメラとマイクを使って動画撮影（`.mp4` / `.webm`）を開始・停止します。初期設定では「カメラ録画開始」を押すと同時にプロンプターの音声追従も自動スタートし、「録画停止」を押すと画面左上に録画プレビューと **「動画を保存 (.mp4 / .webm)」** ボタンが表示されます。

#### キーボードショートカット（撮影モード中）

## 5. 詳細カスタマイズ項目（プロンプター表示・追従設定）

画面右上の設定アイコンをクリックすると開くモーダル画面で、以下のすべての項目をリアルタイムに調整・自動保存できます。

### 5.1 文字・レイアウト設定
- **文字サイズ**：`16px` 〜 `100px`（標準 `42px`）
- **行間 (Line Height)**：`1.20` 〜 `2.50`（標準 `1.65`）
- **文字表示領域の幅**：`30%` 〜 `100%`（幅を狭めることで左右の目線移動を最小化できます）
- **左右余白 (Padding)**：`0px` 〜 `200px`
- **上下余白**：`10vh` 〜 `50vh`
- **文字揃え**：左揃え / 中央揃え / 右揃え
- **反転表示**：
  - **左右反転**：ハーフミラー型テレプロンプター機材に反射させて使う場合にONにします。
  - **上下反転**：スタンドの向きに合わせて上下を反転させる場合にONにします。
- **文字色・背景色**：ワンクリックプリセット（白・黄・水色・緑 / ピュアブラック・ダークグレー・ネイビー）および自由なカラーピッカー選択に対応。

### 5.2 カメラ目線モード・フォーカスモード設定
- **カメラ目線モード**：ONにすると、MacBookのWebカメラ（ノッチ部分）のすぐ真下に表示領域を集約します。
  - **表示領域の高さ**：`20vh` 〜 `85vh`（標準 `42vh`）
  - **上端からの位置オフセット**：`0vh` 〜 `30vh`（標準 `2vh`）
- **フォーカスモード**：ONにすると、現在読んでいるフレーズのみを不透明度100%で表示します。
  - **周囲の文章の明るさ**：`12%` 〜 `75%`（標準 `28%`）
  - **現在位置の細いガイドラインを表示**：読み上げ基準位置を示すスカイブルーの水平ガイドラインの表示/非表示。

### 5.3 スクロール・音声追従パラメータ
- **読み上げ位置の表示高さ**：画面上端から `15%` 〜 `60%`（標準 `32%`）。カメラレンズに最も近い位置へ基準ラインを合わせることができます。
- **一定速度スクロールの速さ**：`10 px/秒` 〜 `260 px/秒`（標準 `65 px/秒`）
- **スクロールアニメーション時間**：`150 ms` 〜 `800 ms`
- **音声追従感度**：`35%` 〜 `90%`（標準 `65%`）。高くすると短い発話やわずかな一致でも素早く次の文へ進み、低くするとより厳密な一致を求めます。
- **次の文・段落へ移るタイミング（先行送り率）**：`40% 時点` 〜 `95% 時点`（標準 `90% 時点`）。現在の文章の何割まで読み上げた時点で次のフレーズ・段落へスクロールさせるかを調整できます。値を小さく（例：`50%`〜`60%`）すると、文末を言い切る前の途中認識（`interim`）の段階で先回りして次の段落・文章がせり上がってきます。
- **前方進行ロック（一度進んだら戻らない）**：標準で **ON**。一度スクロールして進んだ段落・フレーズからは、音声認識で自動的に後ろへ逆戻りしないようにロックします（画面上の段落クリックや矢印キー等の手動操作ではいつでも戻れます）。
- **スクロールの滑らかさ（減衰係数）**：`0.06`（しっとり滑らか）〜 `0.30`（俊敏に追従）
- **追従速度倍率**：`0.5x` 〜 `2.0x`

### 5.4 MacBookカメラ・USB接続スマホカメラ＆マイク撮影設定
- **使用するカメラ（USB接続スマホ / 内蔵カメラ）**：
  - MacBook内蔵カメラ（FaceTime HDカメラ）だけでなく、**USB接続したスマートフォン（Google Pixel等のAndroid Webcam、iPhoneの連係カメラ、Camo / Iriun等）** を直接選択して撮影できます。
  - 「自動選択」にしておくと、USB接続されたスマホカメラが検出された際に自動的にスマホ側の高画質カメラを優先して起動します。また、撮影画面を開いたままUSBケーブルを抜き差ししてもホットプラグ（自動再検出）されます。
- **使用するマイク（外部マイク / スマホ / MacBook）**：
  - 映像は「USB接続したスマホのカメラ」を使いながら、音声は「MacBookに接続した高音質USBマイク（またはピンマイク・スマホ内蔵マイク）」を使うといった**カメラとマイクの個別指定**が可能です。指定したマイクは動画録画の音声トラックとリアルタイム音声追従の音量メーターの両方に反映されます。
- **録画解像度（スマホ高画質対応）**：
  - **`Full HD (1080p)`**（標準） / **`4K UHD (2160p)`**（スマホ高画質センサー用） / **`HD (720p 軽量)`** から選択できます。
- **画面比率（横動画 / ショート縦動画）**：
  - **`16:9 横画面 (YouTube標準)`** と **`9:16 縦画面 (YouTube Shorts / Reels / TikTok)`** をワンクリックで切り替えられます。
- **カメラプレビューの表示スタイル**：
  - **小窓表示 (カメラ直下)**：MacBookのWebカメラ（ノッチ部分）のすぐ真下にコンパクトなワイプ窓を表示し、カメラ目線を保ったまま自分の表情・画角を確認できます。小窓内のプルダウンから**カメラとマイクをその場で直接切り替えることも可能**です。
  - **背景透過 (文字の背面)**：ステージ背景全体にカメラ映像を透過表示し、その上にプロンプターの原稿テキストを重ねて表示します。
  - **プレビュー非表示**：録画は継続したまま、画面上のカメラ映像だけを非表示にして原稿表示に100%集中できます。
- **背景透過時のカメラ映像の濃さ**：`15%` 〜 `85%`（標準 `35%`）
- **プレビュー映像を鏡像（左右反転）表示**：ONにすると鏡を見る感覚で自然に姿勢や身振りを調整できます。
- **録画開始と同時に音声追従も自動スタート**：ONにすると、下部ドックの「● カメラ録画開始」ボタンを押した瞬間に音声認識スクロールも自動で開始されます。

#### 💡 MacBookにUSB接続したスマホをカメラとして使う手順
1. **Google Pixel / Android（Android 14以降）の場合**
   - スマホとMacBookをデータ通信対応のUSB-Cケーブルで接続します。
   - スマホ画面の上部通知 **「このデバイスをUSBで充電中」** をタップし、「USBの用途」から **「ウェブカメラ (Webcam)」** を選択します（Pixelでは高画質モードやズーム倍率もスマホ画面上で調整可能です）。
   - VoiceSync Teleprompter の設定画面（または小窓プレビュー）で **`📱 Android Webcam`** が自動認識・選択されます。
2. **iPhone（macOS 連係カメラ / Continuity Camera）の場合**
   - MacBookと同一Apple IDのiPhoneをUSB接続（またはWi-Fi/BluetoothをONにして近くに配置）すると、**`📱 iPhone カメラ`** として認識され、そのまま選択・録画できます。

## 6. 音声追従アルゴリズムの仕組み（技術仕様）

[`src/lib/scriptParser.ts`](../src/lib/scriptParser.ts) および [`src/lib/fuzzyMatcher.ts`](../src/lib/fuzzyMatcher.ts) に実装されている原稿位置推定アルゴリズムは以下の6ステップで動作します。

1. **フレーズ単位への自動セグメント分割**：
   原稿を改行・句点（`。！？`）・ピリオドで分割し、さらに1文が65文字を超える長文は読点（`、`）で12〜50文字程度の自然な読み上げフレーズ（[`ScriptSegment`](../src/types/prompter.ts)）に分割します。
2. **認識テキストと原稿の正規化**：
   NFKC正規化（全角英数字・半角カナ統一）、カタカナからひらがなへの統一、句読点や記号・空白の除去、および頻出漢字（「皆さん→みなさん」「今日→きょう」「動画→どうが」「撮影→さつえい」など）の表記揺れ吸収を行います。
3. **現在位置周辺の局所優先探索**：
   現在位置から後方5フレーズ〜前方15フレーズの探索ウィンドウを設定し、計算量を $O(1)$ に抑えて100段落以上の長文原稿でも数ミリ秒以内で照合します。直後のフレーズ（`+1`〜`+2`）に高い近傍重みを付与します。
4. **スライディングウィンドウ & Bigram Dice 類似度計算**：
   完全一致に依存せず、文字2-gram（Bigram）のDice係数とセグメント内部分文字列スライディングウィンドウを組み合わせることで、言い間違いや一部単語の省略があっても高い精度で一致度を算出します。
5. **低信頼度・短発話時のホールド（現在位置維持）**：
   「えーっと」などのフィラー（3文字未満）や、原稿にないアドリブ説明を追加して類似度がしきい値を下回った場合は、誤って別位置へ飛ばないよう現在位置をピタッと維持します。
6. **大ジャンプ・読み直しへのヒステリシス制御**：
   前の文章を読み直す場合（逆方向移動）や、途中の文を飛ばして次の段落へ飛ぶ場合（`+3`セグメント以上の移動）には、通常進行よりも高い一致度しきい値（`baseThreshold + 0.22〜0.24`）と6文字以上の発話長を要求し、認識結果の一時的な揺らぎによる画面の前後ガタつきを防止します。

## 7. MacBookとiPad間の原稿同期・バックアップ方法

編集画面左上の **クラウドアイコン（原稿同期・バックアップ）** をクリックすると、[`SyncModal`](../src/components/SyncModal.tsx) が開きます。

### 方法1：AirDrop / iCloud Drive ファイル同期（完全無料・設定不要）
1. MacBookで原稿を編集後、同期モーダルの **「同期データを書き出す (.json)」** をクリックします。
2. 書き出された `.json` ファイルを AirDrop または iCloud Drive / Google Drive 経由で iPad へ渡します。
3. iPad側の VoiceSync Teleprompter で **「同期データを読み込む (.json)」** を選択すると、全原稿が統合されます。

### 方法2：クラウドエンドポイント双方向同期
独自のREST JSONエンドポイント（GET/PUT対応）と認証トークン（任意）を設定し、**「クラウドと双方向同期を実行」** を押すとワンクリックで同期されます。

### 競合保護（データ消失防止仕様）
- 同一IDの原稿がMacBookとiPadの両方で直近（60秒以内）に別内容へ編集されていた場合、片方を上書き消去せず、自動的に **`(競合バックアップ)`** というタイトルの別原稿として両方のデータを残します。
- 通信エラーやオフライン時はローカルの IndexedDB データを一切変更せず安全に保護します。

## 8. トラブルシューティング（マイク権限エラー・音声が認識されない場合）

撮影画面で「エラー」バッジが表示された場合は、画面上部に表示される復旧バナーの手順に従ってください。

1. **「マイクへのアクセスが拒否されました」と表示される場合**
   - ブラウザのアドレスバー左側のアイコン（鍵マーク、調整アイコン、またはマイクアイコン）をクリックし、「マイク」の権限を **「許可」** に変更してから「音声認識を再試行」を押してください。
   - **macOSの場合**：「システム設定」＞「プライバシーとセキュリティ」＞「マイク」を開き、使用しているブラウザ（Google Chrome / Safari）のスイッチがオンになっているか確認してください。
   - **iPadOSの場合**：「設定」アプリ ＞「Safari」＞「マイク」を許可し、あわせて「設定」＞「一般」＞「キーボード」＞「音声入力を有効にする」がオンになっているか確認してください。
2. **音声認識を使用せずにすぐ撮影を続けたい場合**
   - エラーバナー内の **「一定速度スクロールで撮影を続行」** または **「手動モードへ切替」** ボタンを押すことで、マイクを使わずにそのまま撮影を続行できます。
3. **マイクを出さずに原稿照合の動きをテストしたい場合**
   - 撮影画面右下の「リアルタイム音声認識・照合デバッグ」パネルにある **「発話シミュレート入力（テスト用）」** に原稿のフレーズを入力して「照合テスト」ボタンを押すと、実際に声を出さなくても音声追従スクロールの動きを確認できます。

## 9. Vol.2 アップデート追加機能（撮影実用性・信頼性強化）

### 9.1 撮影開始カウントダウン（Phase 1）
- **機能概要**：録画開始ボタンを押してから姿勢を整え、カメラを見て自然に話し始められるよう、画面中央に `3 → 2 → 1 → ● REC` のカウントダウンを表示します。
- **設定項目（設定画面 ＞ カメラ＆マイク設定）**：
  - **カウントダウン時間**：`なし (0秒)` / `3秒 (標準)` / `5秒` / `10秒`
  - **カウントダウン音 / REC開始通知音**：標準ではマイク録音への混入を防ぐため `OFF` です。必要に応じて `ON` に切り替えられます。
  - **録画開始後の無音待機時間（0〜3秒）**：`MediaRecorder` が実際に録画状態（`recording`）に入ったことを確認した後、指定秒数だけ待ってから音声追従を自動スタートします。動画冒頭に自然な間を作りたい場合に便利です。
- **キャンセル・安全設計**：カウントダウン中に画面中央のキャンセルボタンまたは `Esc` キーを押すと録画開始を取り消せます。また、カメラや `MediaRecorder` の起動に失敗した場合は、音声追従のみが単独で走り出す不整合を防止します。

### 9.2 録音品質・環境ノイズ・音声認識チェック（Phase 2）
- **機能概要**：撮影画面上部の **「録音テスト」** ボタンを押すと、撮影前に最大10秒間のテスト録音を行い、マイク入力品質と音声認識の動作を診断します（カメラ録画中は実行不可）。
- **測定ステップ**：
  1. **前半2秒間（無音区間）**：話さずに周囲の環境ノイズフロアを測定します。
  2. **後半2〜10秒間（発話区間）**：画面のサンプル文を普段の声量で読み上げます。
- **診断項目**：
  - **総合判定**：`良好` / `音量が小さい可能性` / `音割れの可能性` / `周囲の騒音が大きい可能性` / `マイク入力が検出されない`
  - **音声レベル分析**：RMS、Peak、推定 dBFS、クリッピング（音割れ）疑い回数、無音区間の割合
  - **環境ノイズと簡易SNR（※すべて推定値）**：前半2秒の環境音フロアと発話音量の差から簡易的な信号対雑音比（SNR）の目安を表示します（厳密な音響測定器ではなくブラウザWeb Audioによる推定値です）。
  - **テスト音声のその場再生** と **Web Speech API 音声認識の同時動作確認**（音声認識非対応ブラウザでも録音テスト自体は実行可能）。
  - **プライバシー・ストリーム解放**：テスト音声は外部へ送信されず、モーダルを閉じると録音データおよびマイクストリームは即座に解放されます。

### 9.3 NG・撮り直しマーカーと撮り直し支援（Phase 3）
- **NG記録とショートカット**：撮影中に下部ドックの **「NG記録」** ボタンを押すか、キーボードの **`M` キー（または `N` キー）** を押すと、録画開始からの正確な実経過時間（タイムコード `HH:MM:SS`）・現在フレーズ番号・本文・マーカー種別（`NG` / `撮り直し開始` / `撮り直し完了` / `編集メモ`）を記録します。
- **撮り直し支援（ボタン操作＆キーボードショートカット対応・内部照合位置の完全同期）**：
  「撮り直し支援」パネルを開かなくても、撮影中に以下のキーまたはパネル内ボタンでいつでも4つの位置へ戻れます。

| ボタン名 | 数字キー | カーソルキー | 文字キー | どんなときに使うか |
| :--- | :---: | :---: | :---: | :--- |
| **現在フレーズから再開** | `1` | — | `R` | いま読んでいる文の最初（先頭）から言い直したいとき |
| **1フレーズ戻る** | `2` | `↑` または `←` | — | 1つ前の文に戻って、つながりを良くして言い直したいとき |
| **現在段落の先頭へ戻る** | `3` | `Shift + ↑` | `P` | いま話している段落の最初からまとめて撮り直したいとき |
| **前の見出し・章へ戻る** | `4` | `Shift + ←` | `H` | 1つ前のセクション（`# 見出し` や段落区切り）まで大きく戻りたいとき |

  - ※ 位置を戻した際は、画面上部に `↩ 1フレーズ前へ戻る（フレーズ #3）` の確認バッジが表示され、画面スクロールだけでなく音声認識エンジンの内部照合インデックスおよび累積バッファオフセットも同時に同期されるため、見かけだけ戻ってすぐ元の位置へ飛ばされる現象を防ぎます。
  - 💡 **おすすめの撮影中コンボ**：噛んだ瞬間に **`M` キー（NG記録） → `2` キー（または `↑` キー：1フレーズ戻る）** と押すだけで、マウスに触れず目線を保ったまま1秒で言い直しを再開できます。
- **録画後のシーク再生と書き出し**：録画完了後のプレビューカードにマーカー一覧が表示され、クリックすると動画の該当秒数へ即座にシーク再生します。また **CSV出力**（`timecode,type,scriptPosition,text,note`）および **JSON出力** に対応し、Premiere Pro / Final Cut Pro / DaVinci Resolve 等での編集時の目印として活用できます。

### 9.4 次の文章の先読み表示（Phase 4）
- **3段階の視覚輝度階層**：
  1. **現在読んでいるフレーズ**：不透明度 `100%`（最明表示）
  2. **先読みフレーズ（次の1〜3フレーズ）**：中間輝度（標準 `68%`、距離に応じて段階的に減衰）
  3. **それ以外の周囲の文章**：減光表示（標準 `28%`）
- **設定項目**：「先読み表示フレーズ数」を `OFF` / `次の1フレーズ` / `次の2フレーズ (標準)` / `次の3フレーズ` から選択でき、先読みフレーズの明るさもスライダーで調整可能です。フォントサイズや余白を変えずに不透明度のみで階層を表現するため、スクロール中に文字レイアウトがガタつきません。

### 9.5 日本語音声追従の精度改善（Phase 5）
- **読み・表記揺れの強化正規化（[`japaneseNormalizer.ts`](../src/lib/japaneseNormalizer.ts)）**：
  - **漢数字・アラビア数字の相互統一**：`十五万円` ↔ `15万円`、`二千二十八年八月` ↔ `2028年8月`、`三百五十` ↔ `350` 等を統一（一方で「一緒」「一つ」「一番」等の慣用句は誤って数字変換しないよう保護）。
  - **英語・カタカナ表記の相互統一**：`YouTube` ↔ `ユーチューブ`、`MacBook` ↔ `マックブック`、`iPhone` ↔ `アイフォーン`、`AI` ↔ `エーアイ`、`4K` ↔ `ヨンケー` 等を統一。
  - **同音異義語・頻出漢字の読み統一**：`構成` / `校正`、`変換` / `返還`、`視聴` / `市長`、`仕様` / `使用`、`人工知能`、`機械学習`、`自然言語処理` 等をひらがな読みベースで照合。
  - **フィラー除去と言い直し対応**：`えー`、`あのー`、`えっと` 等の言い淀みを自動除去し、`15万円、いや、18万円` のような自己訂正発話では訂正後のフレーズも評価します。
- **音声認識の自動復旧（[`speechEngine.ts`](../src/lib/speechEngine.ts)）**：無音タイムアウト時は即座に自動再開し、異常終了が連続した場合は指数バックオフ（最大8回）で再試行します。万一音声認識が停止しても、進行中のカメラ録画は一切中断されません。

### 9.6 長時間録画の安全性改善・逐次保存・クラッシュ復旧（Phase 6）
- **5秒ごとのチャンク逐次保存（[`recordingStorage.ts`](../src/lib/recordingStorage.ts)）**：`MediaRecorder.start(5000)` により5秒ごとに映像チャンクを生成し、非同期順序保証キューを介して IndexedDB（`recording_sessions` / `recording_chunks` ストア）へ逐次保存します。メモリ内に全動画データを溜め込まないため、30〜60分の長時間撮影でもメモリ圧迫を最小化します。
- **未完了セッションの自動検出と復旧**：撮影中にブラウザの異常終了やタブ閉じが発生した場合、次回起動時に「前回の録画データが残っています。復旧しますか？」バナーを表示し、保存済みチャンクから動画を再構成してダウンロードできます。
- **ストレージ容量管理と保護機能**：
  - 設定画面の最下部で `navigator.storage.estimate()` による推定空き容量の確認、過去セッションの再ダウンロード、および不要セッションの削除（確認付き）が行えます。
  - 録画中は `beforeunload` による誤離脱警告、Screen Wake Lock API によるスリープ抑制（対応ブラウザのみ）、およびカメラ/マイク切断時の自動保存保護が働きます。
- **ブラウザ別の注意事項**：
  - macOS では Google Chrome の利用を最も推奨します（Web Speech API と MediaRecorder WebM/MP4 の安定性が最も高いため）。
  - iPadOS Safari では OS 側のメモリ制限やスリープ挙動が厳しいため、長時間撮影時はこまめに不要な録画セッションを削除し、本体の自動ロックをオフにしてご利用ください。

## 10. Vol.3 アップデート追加機能（Elgato Virtual Prompter 研究に基づく高度撮影支援）

Elgato Virtual Prompter の機能分析に基づき、ナレーション撮影・プレゼンテーション配信・長尺動画収録の実用性をさらに高める 5 つの高度機能を完全クライアントサイド（無料・オフライン完結）で追加しました。

### 10.1 ト書き・演出指示の視覚バッジ化と音声認識スキップ
- **機能概要**：原稿内のナレーター向け指示（`[笑顔で目線]` や `【1秒ポーズ】` など）を検出すると、自動的に専用のバッジ（`[演出]` `[ポーズ]`）として上品なグレー背景で視覚化します。
- **音声認識スキップ**：ト書き部分は、音声追従エンジンの「声に出して読む照合テキスト（`spokenText`）」から完全に除外されます。ト書きを声に出して読まなくても、前後の発話にスムーズに同期して原稿がスクロールします。
- **ト書きのみ行の保護**：単独で `【1秒ポーズ】` や `[深呼吸]` と書かれた行は、見出しや発話文として誤認識されず、次の発話文への追従が滞りません。
- **文字数・読み上げ時間の正確化**：原稿エディタ上の「文字数カウンター」および「想定読み上げ時間」の計算からト書きを自動除外し、実際にナレーションする文章量だけに基づいた正確な時間を算出します。

### 10.2 キーワード強調ハイライト（3色対応 ＆ クイック挿入バー）
- **Markdown風の直感的な3色ハイライト記法**：
  - `**黄色で強調したい言葉**`：重要キーワード（イエローハイライト）
  - `==水色で強調したい言葉==`：補足・専門用語・トーン変化（スカイブルーハイライト）
  - `!!赤色で強調したい言葉!!`：注意点・NGワード警告・感情を込めるフレーズ（ローズレッドハイライト）
- **原稿エディタのクイック挿入バー**：エディタ上部のワンクリックツールバーから、見出し `#`、`[笑顔で]`、`【1秒ポーズ】`、各色ハイライトを直感的に挿入できます。

### 10.3 章・見出しインデックスとリアルタイム残り時間の可視化
- **自動チャプター生成**：`# 見出し`、`## 見出し`、`【第2章 本編の解説】`、`■ 見出し`、`Chapter 1` などの記法を自動検出し、セクション目次を構成します。
- **チャプターナビゲーション**：撮影画面左上に「チャプター目次」ドロップダウンを常設。クリックすると該当章の先頭へ即座にジャンプし、音声照合インデックスも同期されます。
- **リアルタイム残り時間・進捗率表示**：
  - 現在読んでいるフレーズの進行状況に応じて、原稿全体の「進捗率（%）」「残り文字数」「残り想定時間（分秒）」をリアルタイムに画面上部へ表示します。
  - チャプター目次内でも各章のフレーズ番号と進捗バッジがリアルタイムに更新されます。

### 10.4 カラオケ風 リアルタイム文字進捗ハイライト
- **機能概要**：現在発話中のフレーズ内で、認識された言葉の位置に合わせて文字単位でゴールド/アンバー色に滑らかにハイライトが進行（ワイプ）します。
- **効果**：長めの1文であっても、「いま文のどの単語まで声に出したか」が一目で把握でき、早口になったり読み飛ばしたりするミスを防止できます。
- **ON/OFF設定**：設定画面 ＞ プロンプター設定の「カラオケ風 文字進捗ハイライト」トグルでいつでも有効/無効を切り替えられます。

### 10.5 最前面フロート小窓（Document Picture-in-Picture / ミニプロンプター）
- **機能概要**：撮影画面上部の「フロート小窓（PiP）」ボタンを押すと、ブラウザ標準の **Document Picture-in-Picture API**（非対応環境ではポップアップ小窓）により、画面最前面に固定されるコンパクトなプロンプターウィンドウを起動します。
- **マルチタスク収録・プレゼン配信**：Zoom、Microsoft Teams、OBS Studio、Keynote、PowerPoint などのスライドやカメラ映像の上に重ねてプロンプターを配置でき、自然なカメラ目線を維持したままプレゼンや動画収録が行えます。
- **親ウィンドウとの完全同期**：
  - 小窓内でも音声追従スクロール、先読み表示、ト書きバッジ、強調ハイライトがリアルタイムに連動します。
  - 小窓の下部ツールバーから、再生/一時停止、フォントサイズ変更（A- / A+）、NG記録、撮り直しジャンプ（1フレーズ戻る等）の操作が直接行えます。

### 10.6 Bluetoothリモコン・左手デバイス対応「ショートカットキー割り当てカスタマイズ」
- **機能概要**：設定画面 ＞「ショートカットキー設定」タブにて、市販のBluetoothプレゼンター（リング型リモコン等）や左手デバイス、フットペダルのお好きなキーを押すだけで、直感的にキーバインドをキャプチャ・保存できます。
- **カスタマイズ対応アクション**：
  1. **再生 / 一時停止**（標準：`Space`）
  2. **NGマーカー記録**（標準：`m` / `n`）
  3. **現在フレーズから再開**（標準：`1` / `r`）
  4. **1フレーズ戻る**（標準：`2` / `ArrowUp` / `ArrowLeft`）
  5. **現在段落の先頭へ戻る**（標準：`3` / `p`）
  6. **前の見出し・章へ戻る**（標準：`4` / `h`）
- **標準設定への復元**：「標準キーに戻す」ボタンを押すことで、いつでも工場出荷時の標準キー配列へワンクリックで戻せます。
- **IME安全対策**：日本語入力（IME変換中）のキー押下（`isComposing` / `keyCode 229`）ではショートカットが誤発火しないようガードされています。
