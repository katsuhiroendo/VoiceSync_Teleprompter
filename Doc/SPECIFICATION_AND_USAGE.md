# VoiceSync Teleprompter 仕様書・ユーザーガイド

## 1. 概要とプロジェクトの目的

**VoiceSync Teleprompter** は、YouTube動画などの撮影時に、撮影者がカメラ目線を維持しながら日本語または英語の原稿を自然に読み上げられる個人利用向けの音声追従型テレプロンプターWebアプリケーションです。

### 最大の特徴
- **リアルタイム音声追従スクロール**：単純な音量検出や固定速度スクロールではなく、マイクから取得した発話内容をリアルタイムに音声認識し、原稿とファジー照合して現在位置を特定・自動スクロールします。
- **自然な話し方への適応**：ゆっくり話した場合、速く話した場合、途中で数秒〜10秒以上沈黙した場合、言い間違いや一部単語の省略、原稿にないアドリブの挿入、前の文章の読み直し、次の段落へのジャンプに柔軟に対応します。
- **カメラ目線モード & フォーカスモード**：MacBook内蔵カメラの直下に原稿表示領域を集約する「カメラ目線モード」や、現在読んでいるフレーズだけを明るく強調する「フォーカスモード」を搭載しています。
- **完全無料・オフライン耐性・マルチデバイス対応**：ブラウザ標準の IndexedDB と Web Speech API / Web Audio API を活用し、外部の有料API課金なしで運用できます。

## 3. 起動方法・セットアップ手順

### 3.1 GitHub Pages（Web公開版）での利用とデプロイ手順
本リポジトリには GitHub Actions による静的エクスポート自動デプロイ（[`.github/workflows/deploy.yml`](../.github/workflows/deploy.yml)）が設定されており、ワークフロー内の `actions/configure-pages@v5` (`enablement: true`) によって GitHub Pages の構成と公開が自動で行われます。

- **公開URL**：`https://katsuhiroendo.github.io/VoiceSync_Teleprompter/`
- **初回有効化手順とエラー時（赤い `×` 表示）の対処法**：
  1. **リポジトリの公開設定の確認**：無料の GitHub アカウントで GitHub Pages を利用する場合は、リポジトリが **Public** である必要があります（Private の場合は **Settings ＞ General ＞ Danger Zone ＞ Change repository visibility** から Public に変更してください）。
  2. **Pages ソース設定の確認**：GitHubリポジトリ（`https://github.com/katsuhiroendo/VoiceSync_Teleprompter`）の上部メニュー **Settings** ＞ 左メニュー **Pages** を開き、**Build and deployment ＞ Source** が **`GitHub Actions`** になっていることを確認します（`Deploy from a branch` になっている場合は `GitHub Actions` に切り替えます）。
  3. **ワークフローの再実行（Re-run）**：設定切り替え前に実行された Actions がエラー（×）になっていた場合は、上部メニューの **Actions** タブを開き、該当のワークフローを選択して右上の **「Re-run all jobs」** をクリックします。
  4. **公開完了の確認**：`build` と `deploy` ジョブが緑色のチェックマーク（✓）になると、MacBook・iPad・スマートフォンのブラウザから上記公開URLを開くだけで、インストール不要ですぐに利用できます。
  5. **以降の更新**：`main` ブランチへ `git push` するたびに、自動的に単体テスト（`npm test`）と本番ビルド（`npm run build`）が走り、最新バージョンが公開URLへ反映されます。

### 3.2 ローカル開発サーバーでの起動
プロジェクトルートで以下のコマンドを実行します。

```bash

npm install

# 開発サーバーの起動
npm run dev
```

ブラウザで `http://localhost:3000` を開くとアプリケーションが起動します。

### 3.3 本番ビルドと起動・テスト実行
```bash
# 自動テスト（Vitest）の実行
npm test

# TypeScript 型チェック
npx tsc --noEmit

# 本番ビルド（静的エクスポート out/ ディレクトリ生成）
npm run build
```

### 3.4 iPad / スマートフォン（PWA）でのホーム画面追加手順
1. Safari（iPadOS）または Chrome（Android）でアプリケーションURLを開きます。
2. ブラウザの共有メニューから **「ホーム画面に追加」** を選択します。
3. アドレスバーのないフルスクリーンアプリ（Standalone PWA）として起動でき、撮影時の表示領域を最大化できます。

## 4. 画面構成と基本的な使い方

アプリケーションは誤編集防止のため、**「原稿編集画面（編集モード）」** と **「プロンプター撮影画面（撮影モード）」** の2つに完全に分離されています。

### 4.1 原稿編集画面（編集モード）
起動直後に表示される画面です。左側のサイドバーで原稿一覧を管理し、右側のメインエディタで本文を執筆します。

1. **新規原稿の作成**：左上の **「＋ 新規原稿」** ボタンを押すと新しい原稿が作成されます。
2. **タイトル・本文の編集と自動保存**：タイトル欄や本文エリアに入力すると、即座にブラウザ内の IndexedDB へ自動保存されます（画面上部に「IndexedDB保存済」と表示されます）。ブラウザを閉じてもデータは消えません。
3. **言語の切り替え**：画面右上の言語セレクターから **「日本語 (ja-JP)」** または **「English (en-US)」** を選択します。選択した言語に合わせて音声認識エンジンと想定読み上げ時間の計算が切り替わります。
4. **キーワード検索**：左サイドバーの検索ボックスにキーワードを入力すると、タイトルおよび本文からリアルタイムに絞り込み検索ができます。
5. **原稿の複製・削除**：原稿リストの各項目にカーソルを合わせる（またはタップする）と、右側に **複製アイコン** と **削除アイコン** が表示されます。
6. **テキストファイルの読み込み・書き出し**：
   - **「ファイル読込 (.txt)」**：手元の `.txt` や `.md` ファイルを読み込んで新規原稿として登録します。
   - **「書き出し (.txt)」**：現在選択中の原稿を `.txt` ファイルとしてダウンロードします。
7. **撮影モードの開始**：右上の **「撮影モードを開始」** ボタンを押すと、原稿がロックされ撮影画面へ切り替わります。

---

### 4.2 プロンプター撮影画面（撮影モード）
カメラ目線での読み上げに集中するための Distraction-Free（不要UI自動非表示）画面です。再生開始後、約3秒間マウスやタッチ操作がないと上下の操作バーが自動的にフェードアウトし、画面タップやマウス移動で即座に再表示されます。

#### 上部ステータス＆クイック設定バー
- **編集へ戻る**：撮影モードを終了し、原稿編集画面に戻ります。
- **状態表示バッジ & マイク音量メーター**：現在の状態（`待機中` / `マイク接続中` / `音声認識中` / `発話検出中` / `原稿照合中` / `一時停止中` / `エラー`）と、マイク入力レベルのリアルタイムインジケーターを表示します。
- **文字サイズ変更（`－` / `＋`）**：撮影画面のままワンクリックで文字サイズ（16px〜100px）を微調整できます。
- **カメラ目線**：MacBook内蔵カメラ直下に表示領域を限定する「カメラ目線モード」のON/OFFを切り替えます。
- **フォーカス**：現在読み上げ中のフレーズを明るく、周囲の文章を暗くする「フォーカスモード」のON/OFFを切り替えます。
- **デバッグ**：画面右下の「リアルタイム音声認識・照合デバッグパネル」の表示/非表示を切り替えます。
- **全画面表示**：ブラウザのフルスクリーン表示を切り替えます。
- **設定アイコン**：詳細な表示・追従パラメータを調整する設定モーダルを開きます。

#### 下部レコーディング操作ドック
- **スクロールモード切替**：
  - **音声追従**：マイクからのリアルタイム音声認識で原稿位置を特定し自動スクロールします（デフォルト）。
  - **一定速度**：設定した速度（`px/s`）で滑らかに等速スクロールします。
  - **手動**：タッチスワイプ、マウスホイール、またはキーボード矢印キーで手動スクロールします。
- **先頭へ**：スクロールを停止し、原稿の1文目（先頭）へ滑らかに戻ります。
- **前段落 / 次段落**：現在位置から前の段落の先頭、または次の段落の先頭へ瞬時にジャンプします。
- **音声認識開始 / 一時停止 / 再開**：メインの再生・停止ボタンです。

#### キーボードショートカット（撮影モード中）
| キー | 動作 |
| :--- | :--- |
| `Space` | 音声認識（または一定速度スクロール）の開始 / 一時停止 |
| `↓` または `→` | 次のフレーズへ1つ進める |
| `↑` または `←` | 前のフレーズへ1つ戻る |
| `Home` | 原稿の先頭へ戻る |
| 任意のフレーズをクリック/タップ | そのフレーズを現在位置に設定し、ガイドライン位置へスクロール |

## 5. 詳細カスタマイズ項目（プロンプター表示・追従設定）

画面右上の設定アイコンをクリックすると開くモーダル画面で、以下のすべての項目をリアルタイムに調整・自動保存できます。

### 5.1 文字・レイアウト設定
- **文字サイズ**：`16px` 〜 `100px`（標準 `42px`）
- **行間 (Line Height)**：`1.20` 〜 `2.50`（標準 `1.65`）
- **文字表示領域の幅**：`30%` 〜 `100%`（幅を狭めることで左右の目線移動を最小化できます）
- **左右余白 (Padding)**：`0px` 〜 `200px`
- **上下余白**：`10vh` 〜 `50vh`
- **文字揃え**：左揃え / 中央揃え / 右揃え
- **反転表示**：
  - **左右反転**：ハーフミラー型テレプロンプター機材に反射させて使う場合にONにします。
  - **上下反転**：スタンドの向きに合わせて上下を反転させる場合にONにします。
- **文字色・背景色**：ワンクリックプリセット（白・黄・水色・緑 / ピュアブラック・ダークグレー・ネイビー）および自由なカラーピッカー選択に対応。

### 5.2 カメラ目線モード・フォーカスモード設定
- **カメラ目線モード**：ONにすると、MacBookのWebカメラ（ノッチ部分）のすぐ真下に表示領域を集約します。
  - **表示領域の高さ**：`20vh` 〜 `85vh`（標準 `42vh`）
  - **上端からの位置オフセット**：`0vh` 〜 `30vh`（標準 `2vh`）
- **フォーカスモード**：ONにすると、現在読んでいるフレーズのみを不透明度100%で表示します。
  - **周囲の文章の明るさ**：`12%` 〜 `75%`（標準 `28%`）
  - **現在位置の細いガイドラインを表示**：読み上げ基準位置を示すスカイブルーの水平ガイドラインの表示/非表示。

### 5.3 スクロール・音声追従パラメータ
- **読み上げ位置の表示高さ**：画面上端から `15%` 〜 `60%`（標準 `32%`）。カメラレンズに最も近い位置へ基準ラインを合わせることができます。
- **一定速度スクロールの速さ**：`10 px/秒` 〜 `260 px/秒`（標準 `65 px/秒`）
- **スクロールアニメーション時間**：`150 ms` 〜 `800 ms`
- **音声追従感度**：`35%` 〜 `90%`（標準 `65%`）。高くすると短い発話やわずかな一致でも素早く次の文へ進み、低くするとより厳密な一致を求めます。
- **次の文・段落へ移るタイミング（先行送り率）**：`40% 時点` 〜 `95% 時点`（標準 `70% 時点`）。現在の文章の何割まで読み上げた時点で次のフレーズ・段落へスクロールさせるかを調整できます。値を小さく（例：`50%`〜`60%`）すると、文末を言い切る前の途中認識（`interim`）の段階で先回りして次の段落・文章がせり上がってきます。
- **スクロールの滑らかさ（減衰係数）**：`0.06`（しっとり滑らか）〜 `0.30`（俊敏に追従）
- **追従速度倍率**：`0.5x` 〜 `2.0x`

## 6. 音声追従アルゴリズムの仕組み（技術仕様）

[`src/lib/scriptParser.ts`](../src/lib/scriptParser.ts) および [`src/lib/fuzzyMatcher.ts`](../src/lib/fuzzyMatcher.ts) に実装されている原稿位置推定アルゴリズムは以下の6ステップで動作します。

1. **フレーズ単位への自動セグメント分割**：
   原稿を改行・句点（`。！？`）・ピリオドで分割し、さらに1文が65文字を超える長文は読点（`、`）で12〜50文字程度の自然な読み上げフレーズ（[`ScriptSegment`](../src/types/prompter.ts)）に分割します。
2. **認識テキストと原稿の正規化**：
   NFKC正規化（全角英数字・半角カナ統一）、カタカナからひらがなへの統一、句読点や記号・空白の除去、および頻出漢字（「皆さん→みなさん」「今日→きょう」「動画→どうが」「撮影→さつえい」など）の表記揺れ吸収を行います。
3. **現在位置周辺の局所優先探索**：
   現在位置から後方5フレーズ〜前方15フレーズの探索ウィンドウを設定し、計算量を $O(1)$ に抑えて100段落以上の長文原稿でも数ミリ秒以内で照合します。直後のフレーズ（`+1`〜`+2`）に高い近傍重みを付与します。
4. **スライディングウィンドウ & Bigram Dice 類似度計算**：
   完全一致に依存せず、文字2-gram（Bigram）のDice係数とセグメント内部分文字列スライディングウィンドウを組み合わせることで、言い間違いや一部単語の省略があっても高い精度で一致度を算出します。
5. **低信頼度・短発話時のホールド（現在位置維持）**：
   「えーっと」などのフィラー（3文字未満）や、原稿にないアドリブ説明を追加して類似度がしきい値を下回った場合は、誤って別位置へ飛ばないよう現在位置をピタッと維持します。
6. **大ジャンプ・読み直しへのヒステリシス制御**：
   前の文章を読み直す場合（逆方向移動）や、途中の文を飛ばして次の段落へ飛ぶ場合（`+3`セグメント以上の移動）には、通常進行よりも高い一致度しきい値（`baseThreshold + 0.22〜0.24`）と6文字以上の発話長を要求し、認識結果の一時的な揺らぎによる画面の前後ガタつきを防止します。

## 7. MacBookとiPad間の原稿同期・バックアップ方法

編集画面左上の **クラウドアイコン（原稿同期・バックアップ）** をクリックすると、[`SyncModal`](../src/components/SyncModal.tsx) が開きます。

### 方法1：AirDrop / iCloud Drive ファイル同期（完全無料・設定不要）
1. MacBookで原稿を編集後、同期モーダルの **「同期データを書き出す (.json)」** をクリックします。
2. 書き出された `.json` ファイルを AirDrop または iCloud Drive / Google Drive 経由で iPad へ渡します。
3. iPad側の VoiceSync Teleprompter で **「同期データを読み込む (.json)」** を選択すると、全原稿が統合されます。

### 方法2：クラウドエンドポイント双方向同期
独自のREST JSONエンドポイント（GET/PUT対応）と認証トークン（任意）を設定し、**「クラウドと双方向同期を実行」** を押すとワンクリックで同期されます。

### 競合保護（データ消失防止仕様）
- 同一IDの原稿がMacBookとiPadの両方で直近（60秒以内）に別内容へ編集されていた場合、片方を上書き消去せず、自動的に **`(競合バックアップ)`** というタイトルの別原稿として両方のデータを残します。
- 通信エラーやオフライン時はローカルの IndexedDB データを一切変更せず安全に保護します。

## 8. トラブルシューティング（マイク権限エラー・音声が認識されない場合）

撮影画面で「エラー」バッジが表示された場合は、画面上部に表示される復旧バナーの手順に従ってください。

1. **「マイクへのアクセスが拒否されました」と表示される場合**
   - ブラウザのアドレスバー左側のアイコン（鍵マーク、調整アイコン、またはマイクアイコン）をクリックし、「マイク」の権限を **「許可」** に変更してから「音声認識を再試行」を押してください。
   - **macOSの場合**：「システム設定」＞「プライバシーとセキュリティ」＞「マイク」を開き、使用しているブラウザ（Google Chrome / Safari）のスイッチがオンになっているか確認してください。
   - **iPadOSの場合**：「設定」アプリ ＞「Safari」＞「マイク」を許可し、あわせて「設定」＞「一般」＞「キーボード」＞「音声入力を有効にする」がオンになっているか確認してください。
2. **音声認識を使用せずにすぐ撮影を続けたい場合**
   - エラーバナー内の **「一定速度スクロールで撮影を続行」** または **「手動モードへ切替」** ボタンを押すことで、マイクを使わずにそのまま撮影を続行できます。
3. **マイクを出さずに原稿照合の動きをテストしたい場合**
   - 撮影画面右下の「リアルタイム音声認識・照合デバッグ」パネルにある **「発話シミュレート入力（テスト用）」** に原稿のフレーズを入力して「照合テスト」ボタンを押すと、実際に声を出さなくても音声追従スクロールの動きを確認できます。
